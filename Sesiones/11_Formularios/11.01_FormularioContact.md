## CSRF - Cross-Site Request Forgey
Opcional: Ver archivo CSRF (explicación de ataque)

Cuando Django renderiza el template (formulario) va incluido un "HTML input"de tipo oculto con el token de seguridad

4. Crear el archivo forms.py y dentro de el, crear la clase ContactForm
```python
from django import forms

class ContactForm(forms.Form):
    # Valida que el nombre contenga al menos 5 caracteres
    name = forms.CharField(min_length=5)
    email = forms.EmailField()
    content = forms.CharField()
```
5. En el archivo views.py
```python
from django.shortcuts import render
from django.http import HttpResponseRedirect
from contact.forms import ContactForm

def contact(request):
    if request.method == 'POST':
        form = ContactForm(request.POST)
        if form.is_valid():
            name = form.cleaned_data.get('name')
            print(f'Datos del formulario {name}')
            return HttpResponseRedirect('/')  # Home
        else:
            errors = form.errors
            return render(request, 'contact/contact.html', {'form': form, 'errors': errors})
    else:  # Método get
        form = ContactForm()
    return render(request, 'contact/contact.html', {'form': form})
```
6. Crear el archivo urls.py
```python
from django.urls import path
from contact import views

contact_urlpatterns = ([
    path('', views.contact, name='contact'),
], 'contact')
```
