## Validaciones personalizadas
### Opción 1 
1. Valida que el dominio del email sea exclusivamente gmail.com
```python
if form.is_valid():
    name = form.cleaned_data.get('name')
    # Otra manera de obtener los datos del formulario
    email = form.cleaned_data['email']
    if 'gmail.com' in email:
        return HttpResponseRedirect(reverse_lazy('contact:thanks'))
    else:
        form.add_error('email', 'dominio inválido')
```

### Opción 2
1. Realizar la valiación desde el mismo formulario
```python
def clean_email(self):
    email = self.cleaned_data['email']
    name = self.cleaned_data['name']
    if 'gmail.com' not in email:
        raise forms.ValidationError('dominio inválido')
    if name in email:
        raise forms.ValidationError(
            'El usuario no puede ser parte del email')
    return email
```
2. También puede realizar validaciones "Generales"
```python
def clean(self):
    cleaned_data = super().clean()
    email = cleaned_data.get('email')
    name = cleaned_data.get('name')
    if name in email:
        raise forms.ValidationError(
            'El usuario no puede ser parte del email')
    return cleaned_data
```
