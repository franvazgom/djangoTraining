# Mejoras al formulario de contacto

1. El formulario puede ser especificado desde la misma creación, por ejemplo: 
```python
name = forms.CharField(required=True, label='Nombre', min_length=5, max_length=100,
                           widget=forms.TextInput(attrs={
                               'class':'form-control',
                               'placeholder':'Escribe tu nombre'
                           }))
    email = forms.EmailField(required=True, min_length=5, max_length=100,
                             widget=forms.EmailInput(attrs={
                                'class':'form-control',
                                'placeholder':'Escribe tu email'
                             }))
    content = forms.CharField(required=True, min_length=5, max_length=1000,
                              widget=forms.Textarea(attrs={
                                'class':'form-control',
                                'placeholder':'Escribe tu mensaje',
                                'rows':'4'
                              }))
```
2. Hacer los siguientes cambios en la plantilla contact.html
```html               
<div class="form-group">                  
    <div class="input-group">
        {{ form.name }}                    
    </div>
    <div class="errores">
        {{ form.name.errors }}
    </div>
</div>          
```
3. Con el objetivo de hacer las validaciones del lado del servidor, se pueden desactivar las validaciones del navegador
```html
<form action='' method='post' novalidate>
```

6. En el archivo views.py modifica el método contact y crea el nuevo método thanks 
```python
return HttpResponseRedirect('/contact/thanks/') 

def thanks(request):
    return render(request, 'contact/thanks.html')
```
7. Actualiza el archivo urls.py
```python

```
8. Verifica su funcionamiento
9. En lugar de hacer uso del path, es mejor hacer uso del nombre definido en el url mediante "reverse_lazy" 
```python
from django.urls import reverse_lazy

# return HttpResponseRedirect('/contact/thanks/') 
return HttpResponseRedirect(reverse_lazy('contact:thanks')) 
```
