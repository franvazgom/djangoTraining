# templatetags
En Django, los templatetags son una forma de añadir funcionalidad personalizada a tus plantillas. Pueden usarse para realizar tareas complejas, filtrar datos o modificar el contenido. 

1.	Dentro de la aplicación "pages", crear la carpeta templatetags
2.	Crear el archivo __init__.py para indicar que es un paquete
3.	Crear el archivo page_extras.py
```python
from django import template
from pages.models import Page

register = template.Library()

# Restrarlo en la librería de templates
@register.simple_tag
def get_page_list():
    pages = Page.objects.all()
    return pages
```
4. En el archivo base.html, verificar que se muestre el contenido
```python
<p class="m-0 mbt">
    {% load page_extras %}
    {% get_page_list %}
```
5. Hacerlo dinámico
```python
{% load page_extras %}
{% get_page_list as page_list %}
{% for page in page_list %}
    <a href="{% url 'page:page' page.id %}" class="link">{{ page.title }}</a>
    {% if not forloop.last %}·{% endif %} 
{% endfor %}
```
