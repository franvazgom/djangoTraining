# Debugging
Existen diferentes formas de hacer un debugging en python y django
## Breakpoint
Simplemente coloca la instrucción "breakpoint()" en el código, al momento de detenerse la ejecución se muestra la terminal
## shell (acceso a la base de datos desde la terminal)

python manage.py shell
