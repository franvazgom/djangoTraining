# Práctica App – Restaurante

1. Descomprimir el archivo “Restaurante_Frontend.zip”
2. Revisar el contenido de las páginas estáticas
3. Verificar su funcionamiento
4. Trabajar con el mismo entorno virtual
5. Crear el proyecto  “webrestaurante” (django-admin...)
6. Crear la aplicación “core” (startapp ...)
    + Crear la estructura para los templates
    + Crear la estructura static y copiar el archivo css e imágenes correspondientes
    + Crear la página base.html: Configurar la parte estática para el css, agregar el template tag de bloque
    + Crear la página home.html: (usa de guía el archivo home.html del proyecto webpersonal)
    + Dentro del archivo views.py: Configurar el método home para regresar la plantilla home.html
7. Configurar el archivo settings.py
    + Lenguaje y zona horaria 
    + Agregar las aplicaciones: “core” y “django_cleanup”
    + Configura las variables: MEDIA_URL y MEDIA_ROOT
8. Dentro de la carpeta webrestaurante, en el archivo urls.py
    + Configurar el path correspondiente para el home
    + Configurar el manejo de imágenes MEDIA_URL
9. Realizar la migración de datos (makemigrations, migrate ... )
10.	Crear el superusuario “admin” con password: “password” 
11.	Verificar su funcionamiento

<b> La solución se encuentra en la carpeta v1.0 </b>

    + Configurar el método visit_us para regresar la plantilla visit_us.html

5. Modifica el navBar para hacer referencia a las páginas:
