### Herencia en plantillas - Template tag block
1.	Dentro de la carpeta templates\core, crear el archivo base.html
2.	Copiar el código que se repite y crear un templete tag por cada sección que se requiera incluir en las demás páginas. 
```python
{% block content %} {% endblock %}
```
Ejemplo: 

```html
...
</div>
    </div>
  </nav>
    <!-- block es el nombre del "bloque" de contenido -->
    {% block content %} {% endblock %}  

  <!-- Footer -->
  <footer id="main-footer" class="bg-dark">
    <div class="container">
...

```
3.	Ahora, dentro del archivo home.html hacer uso de la herencia
```python
{% extends 'core/base.html' %}
```
Colocar el contenido de la página, dentro del bloque.. 

```html
{% extends "core/base.html" %}
{% block content%}
<!-- Home Section -->
<header id="home-section">
  <div class="dark-overlay">

...

</div>
</section>
{% endblock %}
```

### Template tag url
4. En el archivo base.html, reemplazar las urls directas haciendo uso del template tag url


### Archivos estáticos
Los recursos estáticos son: 
+ Archivos js
+ Archivos css
+ Imágenes

Para poderlos manejar, se debe crear la siguiente estructura: 
+ Dentro del directorio “core” crear la carpeta static/core 
+ Copiar los archivos estáticos correspondientes 

Django buscará todos los directorios estáticos de todas las aplicaciones para poderlos despachar. 

En el template Base se debe indicar que “cargue” los archivos estáticos dentro del “head” mediante el siguiente tag 

```python
{% load static %}
```
5. Carga los archivos estáticos del archivo base.html:

```html
  {% load static %}
  <link rel="stylesheet" href=" {% static 'core/css/style.css' %} " />
  <title>Inicio | Francisco Vázquez</title>
```

6. Carga los archivos estáticos del archivo home.html:
```html
{% block content%}
{% load static %}
<!-- Home Section -->
...
      <div class="col-md-6">
        <img src=" {% static 'core/img/courses.jpg' %} " class="img-fluid mb-3 rounded-circle" />
      </div>
      ... 
```
7. Levatar el servidor y verificar su funcionamiento
