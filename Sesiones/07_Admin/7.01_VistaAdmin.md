## list_display
En el archivo admin.py de la aplicación "blog", modificarlo de la siguiente manera. 
```python
class PostAdmin(admin.ModelAdmin):
    readonly_fields = ('created', 'updated',)
    list_display = ('title', 'author', 'published')
```
Observa que muestra lo que se tenga en __str__ de autor, si se desea personaliza la salida, se puede crear un método de la siguientes 2 maneras 

### Opción 1. Dentro del mismo archivo admin.py 
```python
    ... 
    list_display = ('title', 'author_name', 'published')

    def author_name(self, obj):
        return obj.author.first_name
```
### Opción 2. Desde el modelo:  
```python
    def author_name(self):
        return self.author.first_name
```

### list_display
```python
    list_display = ('title', 'author__first_name',
                    'published', 'categories_names', )

    def author_name(self, obj):
        return obj.author.first_name

    def categories_names(self, obj):
        res = ''
        for category in obj.categories.all().order_by("name"):
            res += category.name + ", "
        return res[:-2]
    categories_names.short_description = 'Categorías'
```
Se puede optimizar el método categories_names: 

```python
    return ", ".join([category.name for category in obj.categories.all().order_by("name")])
```
