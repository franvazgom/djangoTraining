# Personalizar la administración de Django 
## Ejercicio
1.	En el archivo apps.py realice los siguientes cambios 
```python
from django.apps import AppConfig

class ProjectConfig(AppConfig):
    name = 'project'
    verbose_name = 'Portafolio de proyectos'
```
2.	Agregar la subclase Meta (Metadatos) en la clase del modelo
```python
    ... 
    class Meta: 
        verbose_name = 'Proyecto'
        verbose_name_plural = 'Proyectos'

        ordering = ['-created']
    
    def __str__(self):

```
3.	Para que se muestre en español y con la leyenda adecuada, es necesario inicializar la propiedad verbose_name 
```python
    ...
```

4.	Para extender la clase de Admin y poder mostrar los campos que son solo de lectura se realiza la siguiente configuración en el archivo admin.py
```python
from django.contrib import admin
from .models import Project

class ProjectAdmmin(admin.ModelAdmin):
    readonly_fields = ('created', 'updated')

admin.site.register(Project, ProjectAdmmin)
```
