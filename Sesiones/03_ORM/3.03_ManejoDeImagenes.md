# Manejo de imágenes

Observe donde se guardo el archivo de imagen (en el folder principal)

Para que la imagen se pueda administrar correctamente, es necesario, configurar el directorio “media”.  En el archivo settings.py, realiza lo siguiente: 

1. En el archivo settings.py
```python
from pathlib import Path
import os
...
# Media files
MEDIA_URL = '/media/'
MEDIA_ROOT = os.path.join(BASE_DIR, "media")
```
2.	La siguiente configuración es para indicarles a django que las imágenes de la aplicación proyecto se debe guardar en el directorio project. (archivo models.py)
```python
image = models.ImageField(verbose_name='Imágen', upload_to='project')
```
3. Configurar el archivo urls.py (solo se hace en modo DEBUG)
```python
from django.conf.urls.static import static
from django.conf import settings
...
if settings.DEBUG:
    urlpatterns += static(settings.MEDIA_URL,
                          document_root=settings.MEDIA_ROOT)

```
Verica su funcionamiento: 
+ Ruta de guardado
+ Visualización de la imágen

4. Observa que si elimina un registro, la imagen no se elimina del directorio, para corregirlo solo hay que instalar la siguiente librería e instalarla como aplicación. 

Es necesiario instalar la librería:  django-cleanup 

```bash
pip install django-cleanup 
```

En el archivo settings.py: 

```python
INSTALLED_APPS = [
    ... 
    'django.contrib.staticfiles',
    'django_cleanup',
    'core',
    'project',
]
```
